# Sistema de Cadastro de Clientes

Projeto desenvolvido em **Python**, utilizando **Flask** e **MySQL**, para realizar o cadastro e gerenciamento de clientes.

## Funcionalidades

- Cadastrar clientes
- Listar clientes
- Buscar clientes
- Editar clientes
- Excluir clientes

## Tecnologias utilizadas

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/cadastro-clientes.git
```

2. Instale as dependências:

```bash
pip install flask mysql-connector-python
```

3. Crie o banco de dados no MySQL e importe o arquivo SQL do projeto.

4. Configure os dados de conexão no arquivo `conexao.py`.

5. Execute a aplicação:

```bash
python app.py
```

6. Abra o navegador e acesse:

```
http://localhost:5000
```
